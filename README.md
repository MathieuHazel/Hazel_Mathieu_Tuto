Ce tutoriel va vous apprendre 3 façons différentes de faire un système de "lock and key".

Ce qu'il y a d'inclus dans le tutoriel ;

1) Un système d'interaction simple, mais très efficace.
2) Une porte qui s'ouvre avec une clé qui rentre et tourne dans un cadenas.
3) Une porte qui s'ouvre en interagissant avec un levier.
4) Une porte qui s'ouvre lorsqu'une boite précise est placée dans une zone précise.
5) Création de matériaux (en utilisant des textures pour le levier et en créant deux matériaux brillants pour les portes).
6) Modification de la caméra dans le "blueprint" du joueur pour le passer en "first person" tout en étant dans un projet en "third person".
7) Autre


Si vous comprenez bien la logique derrière les codes de ce tutoriel, vous pouvez ensuite réutiliser ces façons de faire interagir les blueprint ensemble pour faire plusieurs autres choses et donc ce tutoriel à lui seul vous permet d'avoir un petit prototype de jeu vidéo et vous ouvre de plus grandes portes par la suite.
